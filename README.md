# Ember & Grain Studios

Custom pyrography (wood burning) art, live at **[emberandgrainstudios.com](https://emberandgrainstudios.com)**.

## What this is

A portfolio site — not a store. Visitors browse finished pieces by category, see what’s currently for sale, and submit a request through a commission form (for a custom piece *or* to inquire about buying an existing one).

## Site structure

- **Gallery**, filterable by category tabs (e.g. Currently Available, Nursery, Animals, plus “Sarah’s World” for everything)
- **Currently Available** pieces are sorted lowest → highest price
- Pieces can carry a status: Available / Sold / Pending, Please Inquire
- **Commission request form** — for both custom work and inquiries on existing pieces
- Hosted on **GitHub Pages**, custom domain via Porkbun

## Tech

Plain HTML / CSS / JS — no framework, no backend.

## Status

Actively evolving. This repo (and the process of building it) doubles as a running log of decisions and fixes, since a lot of the “why” behind small tweaks (like category ordering, status labels, etc.) lives in conversation history, not just code comments.
